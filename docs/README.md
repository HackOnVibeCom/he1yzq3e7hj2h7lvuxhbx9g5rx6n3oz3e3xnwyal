# Little Things

Little Things is the working product name. The first playable pack is **日常小事 / Everyday Dilemmas**.

- [PRD](PRD.md) covers MVP and acceptance.
- [User flow](USER_FLOW.md) describes starting, inviting, submitting and sharing.
- [Question pack](QUESTION_PACK.md) contains the eight bilingual questions.
- [Result copy](RESULT_COPY.md) specifies every generated result line.
- [Design system](DESIGN_SYSTEM.md) records the current visual rules.
- [Decisions](DECISIONS.md) records settled and open decisions.

The current app is a local Node prototype in `/Users/yic/Documents/ChatGPT/Hackathon/little-things`. Start it with `npm install` and `npm run dev`. Local preview is [http://127.0.0.1:4188/?debug=1](http://127.0.0.1:4188/?debug=1). Demo uses sample data.

Next milestone is one public HTTPS deployment and a real two-phone asynchronous playtest. Publish the server and persistent room storage together, then verify invitations, both submissions, saved PNG, QR destination and the guessing preview.
