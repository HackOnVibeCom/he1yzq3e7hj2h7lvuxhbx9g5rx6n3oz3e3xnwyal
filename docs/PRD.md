# Little Things · Mini PRD v0.2

## Goal

Help friends discover things they would rarely think to ask each other. Players answer independently and use the reveal to start a conversation.

## MVP

- One bilingual pack, **日常小纠结 / Everyday Dilemmas**, with eight shared questions per room. In-progress rooms keep their original pack version.
- Home’s Start Quiz creates a room and opens Q1. A room invite opens the invite cover; Start Quiz joins that room.
- Players arrive via the same link, answer independently, choose a nickname and one of 20 sticker avatars, then submit.
- A personal recap is immediately available after submission. The default is the Pop Cover with three real answers, a selectable card color and a downloadable PNG with QR code.
- Solo recap offers an invite. Once a friend joins, See group results appears above Copy invite link and unlocks for a submitted player once a second answer is in. Later joins never relock it.
- Group answers by option in every room size. Show vote strips for three or more players, tab counts as ranked bars, and assignments in a three-column grid. Group results offers a return to the personal recap at the top and bottom.
- Copy invite link shares the round. The chat preview opens the invite cover. The poster QR opens the separate public Shared recap.

## MVP acceptance

1. Two phones on different networks can open the same public room, join at different times, submit once each and see both sets of answers.
2. Before a friend submits, the host can see and save their own result and invite someone. Once a second player has submitted, either submitted player can open the comparison. A late join leaves the comparison open, and later submissions appear without refreshing.
3. A saved image matches its preview. Its QR opens just the intended recap. A challenge link opens the teaser and never exposes the player's private answer. Check the actual link preview on the intended sharing platform.
4. The room survives the hosting setup’s normal restart behavior. An invalid invite is handled with a clear way back.

## Results pages

Use the revised question-by-question layout for **Shared recap**, the single-player page reached from the poster QR or recap link. Anyone with the link can see the sharer’s nickname, avatar and answers to the eight questions. Communicate that scope before the player shares or saves the poster. The page has no header Share action. **Try the same quiz** opens the pack cover, where Start Quiz creates a new round.

Personal recap shows the same single-player answer sections below its room actions in every room state. Existing poster links keep the three-answer poster.

## Scope after the first public playtest

The MVP starts with five seats. Draft expiry and release of abandoned seats are open. A five-second example ad, local and hosted, validates completion, one extra seat (up to 20 per round), a Done action with automatic return, and invite-copy confirmation. Live ad integration, new question packs, model-generated insights and an interactive guess reveal are follow-up ideas. Product brand and domain are provisional.
